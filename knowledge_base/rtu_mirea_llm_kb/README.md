# РТУ МИРЭА — база знаний для LLM (офлайн)

Пакет файлов, с которыми языковая модель может отвечать на вопросы о РТУ МИРЭА **без доступа к интернету**.

- **Дата данных:** сентябрь 2026 г., с учётом изменений до 15.10.2026.
- **Как собраны:** по официальным ресурсам вуза. Где их не хватало, использованы агрегаторы, реестровые сервисы и СМИ — такие сведения помечены «[неофиц.]».
- **Проверка:** 15.10.2026 перепроверены 328 утверждений; все найденные исправления в базе учтены.
- **Ссылки:** внешних ссылок в тексте нет. Источники обозначены компактными номерами [Иn], а полный список с адресами вынесен в sources.md.

## Как подключить

**1. Модель с большим контекстом (от 128 тыс. токенов).** Загрузите rtu_mirea_kb_full.md целиком, например как файл проекта или вложение. Если платформа не принимает .md, подойдёт .docx; из PDF таблицы извлекаются хуже. Системный промпт — ниже.

**2. Модель с небольшим контекстом (8–32 тыс. токенов).** Используйте rtu_mirea_key_facts.md. Если остаётся место, добавьте нужные фрагменты из chunks/ или rtu_mirea_faq.md.

**3. Поиск по базе (RAG, векторное хранилище):**
- Индексируйте каждый файл из chunks/ как отдельный документ. В начале каждого фрагмента уже есть заголовок, название раздела, дата данных и расшифровка пометок, поэтому фрагмент понятен сам по себе.
- Для табличных вопросов (баллы, цены, руководители, контакты) добавьте data/all_tables.jsonl: одна запись — одна строка таблицы.
- data/faq.jsonl хорошо работает как дополнительный индекс «вопрос → ответ».
- Если фрагменты нужно резать мельче (около 1–2 тыс. токенов), режьте по заголовкам «##» и строкам таблиц и повторяйте шапку таблицы и шапку фрагмента в каждом куске.

**4. Работа с таблицами в коде или в Excel.** Нужные таблицы лежат в data/*.csv (кодировка UTF-8).

## Рекомендуемый системный промпт

```
Ты — справочный ассистент по РТУ МИРЭА. Отвечай только по приложенной базе знаний
(данные на сентябрь 2026 г., изменения до 15.10.2026). Доступа к интернету нет.
Если сведений в базе нет — так и скажи, не выдумывай. Называя людей, должности и цифры,
указывай дату подтверждения из базы, если вопрос касается актуальности. Сохраняй смысл пометок:
[неофиц.] — неофициальный источник; [оценка] — вывод составителя; ≈ — приблизительная дата;
«не подтверждено на 2026» — нет свежего подтверждения. Если источники расходятся, назови обе версии.
С 01.10.2026 в вузе шесть институтов (ИИТ, ИИИ, ИКБ, ИРИП, ИТУ, ИТХТ); ИРИ и ИПТИП вошли в ИРИП.
Номера [Иn] — ссылки на источники; упоминай их, только если спрашивают, откуда сведения.
```

## Что важно знать о данных

- **Нет данных с основных сайтов.** Русскоязычный сайт www.mirea.ru и vk.com во время сбора были недоступны. Часть должностей взята с английской версии сайта или из Telegram-каналов вуза.
- **Даты постов приблизительные.** Большинство дат постов Telegram восстановлены по номеру поста и потому помечены «≈».
- **Руководители не названы.** На 15.10.2026 в доступных источниках нет руководителей ИРИП, ИТХТ и Высшей школы лингвистики.
- **Остальные спорные пункты** перечислены в разделе 11 основного файла.
- **Данные стареют.** После октября 2026 года руководители, составы и цифры могут измениться. При обновлении базы меняйте дату в инструкции и в шапках фрагментов.

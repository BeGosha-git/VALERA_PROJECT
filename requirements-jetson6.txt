#     Версии >= 0.16 требуют torch>=2.10 и тянут torch 2.14 с PyPI.
#   • numpy==1.26.4 — Jetson-сборка torch слинкована с numpy 1.x.
#   • nvidia-cusparselt-cu12 — Jetson-torch слинкован с libcusparseLt.so.0.
#   • torchvision здесь ОТСУТСТВУЕТ намеренно: колесо с PyPI несовместимо по ABI
#     с Jetson-сборкой torch. Собирается из исходников: bash build_torchvision.sh
